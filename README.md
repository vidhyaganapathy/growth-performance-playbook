# Growth & Performance Playbook

**Budget planning, test design and lead-quality reporting across channels.**

The channel playbooks cover *how* to run each platform. This one covers *how to decide*: where the money goes, what to test, and how to judge it.

---

## The system

```
1. Plan the budget     →  01-budget-plan.md
2. Design the tests    →  02-test-design.md
3. Measure what counts →  03-lead-quality-ladder.md
4. Report it           →  04-reporting.md
```

| File | What it's for |
|---|---|
| [`01-budget-plan.md`](./01-budget-plan.md) | Splitting budget across paid, influencer and whitelisting, and across channels |
| [`02-test-design.md`](./02-test-design.md) | Hypotheses, spend caps, kill rules and scale rules |
| [`03-lead-quality-ladder.md`](./03-lead-quality-ladder.md) | Moving from CPL to cost per qualified lead, meeting and pipeline |
| [`04-reporting.md`](./04-reporting.md) | Weekly and monthly reporting templates |

## Principles

- **Qualified leads over CPL.**
- **Kill rules before launch.**
- **Separate budgets, one view.**
- **Every test produces a learning, win or lose.**
