# 04 · Reporting

Reports should answer three questions: **what happened, why, and what we'll do next.**

## Weekly report (internal)

```
Week of [date]

Headline
- Spend: $[ ] ([ ]% of plan)
- Leads: [ ] | CPL: $[ ]
- Qualified leads: [ ] | Cost per qualified lead: $[ ]
- Meetings booked: [ ]

What changed (and why)
- [Biggest change, with the most likely reason]

By channel
| Channel | Spend | Leads | CPL | Qualified | Cost per qualified lead | Trend |
|---|---|---|---|---|---|---|
| Meta | | | | | | |
| LinkedIn | | | | | | |
| Google | | | | | | |
| Whitelisting | | | | | | |

Top and bottom performers
- Top: [ad / campaign] because [reason]
- Bottom: [ad / campaign] because [reason]

Next week
1. [Action, ranked by impact]
2.
3.
```

## Monthly report (founder or client)

1. **Summary in 3 lines:** results vs goal, biggest win, biggest issue
2. **Budget:** spend vs plan, by budget line (paid, influencer, whitelisting)
3. **Results:** the lead-quality ladder, month on month
4. **Tests run:** hypothesis, result, learning
5. **Next month:** plan and budget changes, for approval

## Rules

- **Plain language.** Write for a founder, not a media buyer.
- **Every number has a "so what".**
- **Lead with qualified leads and pipeline**, not impressions.
- **Draft with an agent, decide as a human.** A reporting agent can pull and summarise the data (see [meta-ads-playbook / 04-reporting-agent](https://github.com/vidhyaganapathy/meta-ads-playbook/blob/main/04-reporting-agent.md)); the recommendations are mine.
